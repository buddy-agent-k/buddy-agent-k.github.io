BEFOREBACKGROUND

에이전트는 점점 더 똑똑해지고 있었습니다.

ElizaOS와 AI 에이전트 생태계를 오래 지켜봤고 관련 코인도 샀습니다. 결과는 좋지 않았습니다.

그래도 생각 하나는 남았습니다. 꼭 그렇게 똑똑해야 하나? 조금 부족해도, 기억하고, 가끔 엉뚱하고, 계속 옆에 있는 친구 같은 에이전트는 없을까.

2026.07TRY

김콩을 iPhone 안으로.

작은 로컬 모델, 대화, 선택 비교, 기억을 한 앱 안에 묶기 시작했습니다.

PC에서 검증하던 흐름을 실제 모바일 경험으로 옮기는 과정이 시작됐습니다.

2026.07FIXED

로컬 모델은 그냥 넣는다고 끝나지 않았습니다.

모델 번들, 런타임, 기기 상태 확인, 실제 generate 증거를 따로 검증했습니다. 시뮬레이터에서 되는 것과 실기기에서 되는 것도 구분해야 했습니다.

2026.08ITERATE

기억과 대화 UX를 계속 뜯어고쳤습니다.

사용자가 허락한 기억만 남기고, 세션 대화와 오래 남는 기억을 분리했습니다. 지난 대화, 다시 쓰기, 기록 비우기 같은 작은 동작도 계속 다듬었습니다.

2026.08FAILED → FIXED

번역 대상 언어가 섞이거나 원문 언어가 새어 나오는 문제를 고쳤고, 대화 시작 톤도 다시 맞췄습니다.

2026.08–09TESTFLIGHT

올리고, 보고, 또 고쳤습니다.
