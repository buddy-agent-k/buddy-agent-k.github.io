작은 로컬 모델, 대화, 선택 비교, 기억을 모바일 앱 안에 묶기 시작했습니다.

2026.08FIXED

v1 범위를 다시 줄였습니다.

외부 API를 일단 잠그고 로컬 LLM 중심으로 정리했습니다. 한국어 UI와 모델 고지, App Store 자료도 다시 맞췄습니다.

2026.08–09TESTFLIGHT

올리고, 보고, 또 고쳤습니다.

기억 UX와 번역 화면을 손봤고, 번역 언어가 섞이는 문제도 여러 번 수정했습니다. 대화 시작 말투도 다시 다듬었습니다.

2026.09SHIPPED

빌드 6까지 안정화하고 심사를 통과했습니다. 이제 실제 서비스로 계속 고칠 수 있게 됐습니다.
