1. 개인정보 처리

김콩의 현재 버전은 개발자가 운영하는 서버로 개인정보나 대화 내용을 전송·수집하지 않습니다. 계정 가입, 광고, 개발자 운영 분석 도구, 클라우드 동기화 및 서버 백업 기능도 제공하지 않습니다.

2. 기기 내 처리 및 저장

사용자가 입력한 내용은 앱 기능과 로컬 AI 응답 제공을 위해 해당 iPhone에서 처리됩니다. 사용자가 직접 저장을 승인한 정보만 앱의 로컬 저장 공간에 남을 수 있습니다.

3. 외부 공유

김콩은 사용자 정보를 외부 서비스로 자동 전송하지 않습니다. 사용자가 iOS 공유 기능을 직접 실행한 경우에만 사용자가 확인한 내용이 선택한 앱 또는 서비스로 전달될 수 있으며, 전달 이후의 처리는 해당 서비스의 개인정보 처리방침에 따릅니다.

4. 보관 및 삭제

로컬에 저장한 정보는 사용자가 앱에서 삭제할 때까지 기기에 남을 수 있습니다. 앱 내 삭제 기능을 이용하거나 김콩 앱을 삭제하여 기기 내 앱 데이터를 제거할 수 있습니다.

5. 사용자 선택 및 문의

김콩은 개발자 서버에 사용자 데이터를 보관하지 않으므로 서버에 저장된 개인정보의 조회·복구 대상이 없습니다. 기기 내 정보는 사용자가 앱에서 직접 관리할 수 있습니다.
