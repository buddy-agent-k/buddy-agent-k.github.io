개인정보 처리방침

김콩은 사용자 정보를 가능한 한 기기 안에서 처리하는 로컬 우선 iPhone 앱입니다.

앱 안내지원

1. 처리 목적 및 항목

김콩은 대화·선택 지원, 로컬 AI 응답 및 사용자가 승인한 로컬 저장 기능을 제공하기 위해 사용자가 입력한 내용과 저장을 승인한 정보를 해당 iPhone 안에서 처리합니다.

현재 버전은 개발자가 운영하는 서버로 개인정보나 대화 내용을 전송·수집하지 않습니다. 계정 가입, 광고, 개발자 운영 분석 도구, 클라우드 동기화 및 서버 백업 기능도 제공하지 않습니다.

2. 보유 기간 및 파기

개발자 서버에 보관되는 사용자 개인정보는 없습니다. 기기 내 저장 정보는 사용자가 삭제할 때까지 남을 수 있으며, 앱 내 삭제 기능 또는 앱 삭제를 통해 제거할 수 있습니다.

3. 제3자 제공·위탁·국외 이전

김콩은 개발자가 사용자 정보를 제3자에게 자동 제공하거나 개인정보 처리를 위탁·국외 이전하는 기능을 제공하지 않습니다.

사용자가 iOS 공유 기능을 직접 실행한 경우에는 사용자가 확인한 내용이 선택한 앱 또는 서비스로 전달될 수 있으며, 전달 이후의 처리는 해당 서비스의 개인정보 처리방침에 따릅니다.

4. 사용자 권리 및 행사 방법

사용자 또는 법정대리인은 앱에 저장된 정보를 앱 내 기능으로 관리·삭제하거나 앱을 삭제할 수 있습니다. 개발자 서버에 보관된 사용자 데이터가 없으므로 서버에 저장된 개인정보의 조회·복구 대상은 없습니다.

5. 자동 수집 및 안전성

현재 버전에는 광고 또는 개발자 분석 목적의 추적 도구를 포함하지 않습니다. 로컬 저장 정보는 iOS 앱의 저장 영역에서 처리하며, 저장과 외부 공유는 사용자의 명시적인 동작을 기준으로 합니다.
