앱 안내지원

김콩은 iPhone에서 동작하는 로컬 우선 앱입니다.

계정 가입을 요구하지 않으며, 현재 버전은 개발자가 운영하는 서버로 대화 내용을 전송하거나 저장하는 기능을 제공하지 않습니다.

사용자가 직접 승인한 정보는 해당 iPhone의 앱 저장 공간에 저장될 수 있습니다. 다른 앱으로 내용을 공유할 때에는 사용자가 공유할 내용과 대상을 직접 확인하고 선택합니다.

앱에 저장된 정보는 앱의 삭제 기능을 사용하거나 앱을 iPhone에서 삭제하여 제거할 수 있습니다.
